# Movie Theater Ticket Kiosk
This repository contains a guided software engineering practice example for a movie theater self-service ticket kiosk. The kiosk allows a customer to view available movies and showtimes, choose an available seat, purchase a ticket, and receive a confirmation. The system must also prevent the same seat from being sold twice.

## Homework Scope
This repository is used to practice software engineering tools using the Movie Theater Ticket Kiosk example. The homework focuses on version control, requirements tracking, project management, and UML modeling. No software implementation is required.

## Expanded Use Case: Purchase Ticket

**Primary Actor:** Customer

**Precondition:** The customer has selected a movie, showtime, and an available seat.

**Main Steps:**
1. The customer selects the Purchase Ticket option.
2. The system confirms that the selected seat is still available.
3. The system displays the ticket and payment information.
4. The customer provides the required payment information.
5. The system processes the payment.
6. The system records the ticket purchase for the selected seat and showtime.
7. The system displays a purchase confirmation to the customer.

**Postcondition:** The ticket purchase is completed, the selected seat is no longer available for that showtime, and the customer receives a confirmation.
