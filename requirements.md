# Movie Theater Ticket Kiosk Requirements

## 1. View Available Movies and Showtimes
The customer should be able to view the movies that are currently available in the theater. The system should also show the available showtimes for each movie so the customer can choose when they want to watch it.

## 2. Choose an Available Seat
The customer should be able to view available seats for the selected showtime and choose one seat. The system should only allow the customer to select a seat that is currently available.

## 3. Purchase a Ticket
After selecting a movie, showtime, and seat, the customer should be able to purchase a ticket through the kiosk. The purchase should be completed for the selected seat and showtime.

## 4. Provide a Confirmation
After a successful ticket purchase, the system should provide a confirmation to the customer. The confirmation should indicate that the ticket purchase has been completed successfully.

## 5. Prevent Duplicate Seat Sales
The system must prevent the same seat from being sold to more than one customer for the same showtime. Once a seat has been purchased, it should no longer be available for another customer to select.
